# IPA File Extractor

A simple and modern Windows GUI for IPATool that makes downloading App Store IPA files easier — no command line required.

## ✨ Features

- 🖥️ Simple Windows GUI
- 📦 Download App Store IPA files
- 🔐 Apple ID authentication
- 🔑 2FA support
- 🌍 App Store storefront/region support
- 🚀 Easy-to-use interface
- 🪟 Built for Windows

## 📥 Download

Download the latest Windows executable from the **[Releases](../../releases)** page.

1. Open the latest release.
2. Download `ipatool-gui.exe`.
3. Run the application.
4. Follow the instructions in the application.

## 🛠️ Requirements

For the prebuilt Windows executable:

- Windows 10 or later
- No Python installation required

## ⚠️ Disclaimer

This project is a graphical interface for IPATool.

Downloaded IPA files may be FairPlay-encrypted. This project does not bypass Apple's DRM or security mechanisms.

Use this software only with apps and accounts you are authorized to access, and comply with Apple's terms and applicable laws.
